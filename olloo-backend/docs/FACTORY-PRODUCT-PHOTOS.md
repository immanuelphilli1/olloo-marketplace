# Product photos: how to name and send them

Thank you for sending photos of our products. We put them on our online store automatically, so each photo must have the correct file name. If a photo has the wrong name, we cannot tell which product it shows.

## 1. Use the SKU in the file name

Name each photo with the **SKU** of the product. The SKUs are in the product list that we sent to you.

- If a product comes in several options (for example colours or sizes), each option has its own SKU. You can use the SKU of any option. All the photos go to the same product page.
- Capital or small letters in the SKU are both fine: `TEE-CREW-STD` and `tee-crew-std` are the same.

## 2. Start the name with `main-` or `sub-`

| Start the name with | Meaning | How many |
| --- | --- | --- |
| `main-` | The main photo. Shoppers see it first, on the product card and at the top of the product page. | **1** for each product |
| `sub-` | An extra photo for the product gallery (other angles, details, the label, the packaging). | **Up to 9** for each product |

If a product has more than one `sub-` photo, add a number at the end: `-1`, `-2`, `-3` and so on.

## 3. Examples

For a product with the SKU `TEE-CREW-STD`:

| File name | What it becomes |
| --- | --- |
| `main-TEE-CREW-STD.jpg` | The main photo |
| `sub-TEE-CREW-STD-1.jpg` | Gallery photo 1 |
| `sub-TEE-CREW-STD-2.jpg` | Gallery photo 2 |
| `sub-TEE-CREW-STD-3.jpg` | Gallery photo 3 |

**Wrong names, which we cannot use:**

| File name | Problem |
| --- | --- |
| `IMG_4821.jpg` | There is no SKU in the name. |
| `TEE-CREW-STD.jpg` | There is no `main-` or `sub-`, so we do not know if it is the main photo. |
| `main TEE-CREW-STD.jpg` | Use a hyphen (`-`) after `main`, not a space. |
| `main-TEE-CREW-STD-front-view.jpg` | Do not add words after the SKU. Use only a number, for example `-1`. |

## 4. Photo requirements

- **File type:** JPG, PNG or WEBP.
- **File size:** 5 MB or less for each photo. We cannot use a larger file.
- **Shape:** square (the same width and height). Our store shows product photos as squares. On the product list, a photo with a different shape is cut to a square, and part of the product can be lost.
- **Size:** at least 1200 × 1200 pixels.
- **Main photo:** the full product on a plain white or light background, with no text, logo or watermark.

## 5. How to send the photos

1. Put all the photos in one folder. You can use sub-folders, for example one sub-folder for each product.
2. Do the checks in the list below.
3. Send the folder as a zip file or as a shared link (for example Google Drive or WeTransfer).

## Checklist before you send

- [ ] Every file name starts with `main-` or `sub-`.
- [ ] Every file name has the correct SKU from our product list.
- [ ] Each product has exactly 1 `main-` photo.
- [ ] Each product has 9 `sub-` photos or fewer, with a different number on each (`-1`, `-2`, `-3` and so on).
- [ ] There are no extra words in the file names.
- [ ] Each photo is JPG, PNG or WEBP, and 5 MB or less.

If a SKU contains a character that a file name cannot have (for example `/`), or if a product is not in our list, please contact us before you send the photos.
